## scPhere

This project bundles a modified version of [scPhere](https://github.com/klarman-cell-observatory/scPhere), originally developed at the Broad Institute under the BSD 3-Clause License.

- *Original copyright:* © 2019 The Broad Institute, Inc.
- *Original license:* BSD 3-Clause (see scphere/LICENSE)
- *Original repository:* github.com/klarman-cell-observatory/scPhere

## Modifications

Updated to support TensorFlow 2.x.

Minor packaging changes to enable integration within this repository.

For detailed usage instructions, examples, and scientific background, please refer to the original [scPhere repository](https://github.com/klarman-cell-observatory/scPhere) .
